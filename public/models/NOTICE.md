# Bundled MediaPipe hand models

These TensorFlow.js graph models are the MediaPipe Hands lite detector and landmark models distributed by Google through TensorFlow Hub / Kaggle Models. Source: https://tfhub.dev/mediapipe/tfjs-model/handpose_3d

Model distribution license: Apache-2.0. MediaPipe and TensorFlow.js are Apache-2.0 projects. See https://www.apache.org/licenses/LICENSE-2.0 .

Run `npm run models:download` to reproduce the assets. The original source URLs are recorded in `scripts/download-models.mjs`. Camera images are processed locally; no remote inference service is used.
